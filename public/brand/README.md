# tokener brand files

All files are traced from the approved logo artwork. Vector files are the source of truth.

| File | Use |
|---|---|
| logo-light.svg / png | Long logo on light backgrounds |
| logo-dark.svg / png | Long logo on dark backgrounds |
| logo-mono-ink.svg / png | Long logo, one color ink |
| logo-mono-white.svg / png | Long logo, one color white |
| logomark*.svg / png | Short logo (t and Sigma), light, dark, mono ink, mono white |
| sigma.svg, sigma-ink.svg | Sigma alone |
| app-icon*.svg, png/app-icon-192.png, png/apple-touch-icon.png, png/favicon-*.png | App tiles and favicons |
| brand-sheet.png | Preview of every version on light, dark and accent backgrounds |

Colors: ink #0D1120, deep #07191E, accent #02F5A1.

Do not recolor, stretch, outline or redraw the letters. Keep clear space of one letter n on every side.
Minimum width on screen: long logo 96px, short logo 40px, Sigma 16px.

PNG files have transparent backgrounds.
